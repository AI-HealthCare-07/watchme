## 발표 팁
- 2장과 5·6·7장이 "왜 이 서비스인가"의 핵심이에요. 숫자는 실제 값만 써요(위험도는 예시 인물의 실제 계산값, 사용자 수는 `/admin` 캡처).
- 2장 숫자가 작아도 그대로 써요. "몇 명이 매일 카톡을 받고 있다"는 것 자체가 실제 운영의 증거예요. 테스트 체험을 뺀 기준이라는 걸 한 줄로 밝혀요.
- 14장은 발표 일주일 전 숫자를 보고 채워요. 고친 게 없으면 "어디서 빠지는지 보였다"까지만 말해도 돼요.
- 시연은 8장(영상). 라이브 시연이면 데모 체험(`scripts/seed_demo.py`)으로 리포트·주간 리포트를 바로 보여 줘요.
- 실제 사용자의 체험 링크·카톡 화면은 슬라이드에 넣지 않아요.
