# Watchme 랜딩 개편 + 대표 아이콘 설계 (짧은 설계)

2026-11-18 · 사용자와 시안(브라우저)으로 정함 · 구현·배포 완료(`40c6d9c`)

## 왜
- 랜딩이 "초딩이 만든 것 같은" 단순 화면이라 첫인상이 약하다. 색·분위기(초록)는 유지하되, 화면 전환 애니메이션으로 "제대로 만든 서비스"처럼 보이게 한다.
- 대표 아이콘이 없다. 브라우저 탭, 폰 홈 화면, 카톡 링크 미리보기, 카카오 로그인 동의 화면이 모두 비어 있다.

## 목표 / 하지 않을 것
- 목표: 랜딩을 스토리형 장면 전환으로 바꾸고, 아이콘 하나로 탭·홈 화면·카톡 미리보기를 채운다.
- 하지 않음: 다른 화면(시작·결과·기록) 디자인 변경, 카톡 양방향 대화(채널 챗봇은 범위 밖), 새 라이브러리.
- 실패로 볼 것: 실제 서비스와 다른 기능을 보여 주는 장면, JS가 없거나 움직임을 줄인 환경에서 내용이 안 보이는 것.

## 고른 방향 (시안 비교)
| 시안 | 내용 | 결과 |
|---|---|---|
| 1. 인트로 → 본문 | 로고 애니메이션 후 본문이 열림 | 안 고름 |
| 2. 한 화면 한 장면(스크롤 스냅) | 넘기면 장면 전환 | 마지막 장면만 가져옴 |
| **3. 스토리형 자동 전환** | 인스타 스토리처럼 자동으로 넘어가고, 누르면 다음 | **채택** |

아이콘: 4안(맥박 W, 30일 링, 하트+체크, 눈) 중 **A. 맥박 W** 채택 — 초록 그라데이션 둥근 사각형에 흰 심박선이 W 모양으로 지나감.

## 랜딩 장면 (사용자 결정)
1. (초록) "30일 생활습관 챌린지" / "내 혈압·혈당 위험, 또래 평균과 비교해 보세요" / 국민건강영양조사 출처
2. (흰) "1분 입력" — 예시 45세 남성 위험도 막대가 차오름 (값은 지금처럼 서버가 계산한 `example`)
3. (흰) "맞춤 30일" — 30칸 달력이 차례로 채워지고 자유 한 끼 칸은 노랑
4. (흰) "카톡으로 챙겨 드려요" — **실제와 같은** '나와의 채팅' 메시지 2개(07:30 오늘 계획 + [오늘 계획 보기], 21:00 "오늘 잘 지키셨나요? 10초면 기록돼요." + [기록하기]), 답장 말풍선 없음
5. (초록) "무료 · 이름·연락처 받지 않아요" / "지금 내 위험도부터 확인해 볼까요?" — 여기서는 자동으로 넘어가지 않음

- 맨 위 진행 막대: 장면별 칸이 차오름. **칸을 누르면 그 장면으로 이동**(사용자 요청).
- 화면(가운데 영역)을 누르면 다음 장면.
- 아래 고정: "내 위험도 확인하기" 버튼. 그 밑 작은 글씨 "이미 시작했나요? 카카오로 이어서 하기"(카카오 켜졌을 때만). 초록 장면에서는 흰 글씨.

## 내가 정한 것 (확인 부탁)
- 카톡 장면(4)은 카카오 기능이 켜졌을 때만 넣는다. 꺼져 있으면 4개 장면.
- 개인정보 전체 문구(`privacy()`)는 장면 5 아래 접기(🔒)로 둔다. 지금처럼 랜딩에서 볼 수 있게.
- JS가 없으면 장면 5개가 위에서 아래로 그냥 쌓여 보인다(지금 설정 화면과 같은 방식).
- "움직임 줄이기" 설정이면 자동 넘김·등장 효과를 끄고, 누르거나 진행 막대로만 넘긴다.
- 진행 막대 칸은 버튼(스크린리더에 "n번째 장면")으로 만든다.
- 아이콘은 모든 화면 머리의 "WATCHME" 글자 앞에도 작게 붙인다.
- 아이콘 파일: `favicon.svg`, `apple-touch-icon.png`(180), `icon-192.png`·`icon-512.png` + `manifest.webmanifest`(홈 화면 추가 시 이름 "Watchme"), 카톡 미리보기용 `og.png`(1200×630, 초록 바탕에 아이콘 + 제목 한 줄).
- 카톡 미리보기 태그: `og:title`, `og:description`, `og:image`(절대 주소, `PUBLIC_BASE_URL` 기준).
- 정적 파일 버전 표시(`app.css?v=…`)도 같이 넣는다 — 이번에 CSS가 크게 바뀌므로, 폰에 예전 CSS가 남아 깨져 보이는 일을 막는다.

## 사용자 몫
- 카카오 개발자 콘솔에 앱 아이콘(`icon-512.png`) 올리기.
- 배포 후 카톡 링크 미리보기가 예전 것으로 남아 있으면 카카오 "공유 디버거"에서 캐시 지우기.

## 만드는 사람에게 남긴 것
- PNG는 Pillow(설치됨)로 그리거나, `og.png`처럼 글자가 들어가는 건 Edge/Chrome 헤드리스 스크린샷으로 만든다(Pretendard 사용).
- 장면 시간: 3.0 / 3.6 / 3.8 / 4.6초(시안 값), 마지막 장면은 멈춤.
